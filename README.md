
# Student Portfolio & Academic Planner

Welcome to my personal portfolio website!

## 📌 About the Website

This website showcases my academic journey, technical skills, projects, certifications, achievements and personal interests.

It also features an interactive Academic Planner that helps users organize their study activities and manage tasks effectively.

The website was developed using HTML5, CSS3 and JavaScript with a responsive design that works across desktop, tablet and mobile devices.

Visit my portfolio here:

[View My Portfolio](https://github.com/AngelinaChima/Student_Portfolio)

## ✨ Website Features

### 🏠 Home
- Personal introduction and overview
- Technical skills and interests
- Featured projects
- Navigation to other sections

### 👤 About Me
- Personal biography
- Educational background
- Certifications and achievements
- Hobbies and interests
- Career goals and aspirations

### 💻 Projects
- Showcase of completed projects
- Project descriptions
- Technologies and skills used
- Links to available projects

### 📚 Academic Planner
- Add new academic tasks
- Mark tasks as completed
- Delete unwanted tasks
- Track pending and completed tasks
- Save tasks using browser local storage

**Note:** Planner tasks are stored locally in your browser. They are not synchronized across devices and may be lost if browser storage is cleared.

### 📬 Contact
- Contact information
- Contact form with JavaScript validation
- Links to available professional and social profiles

**Note:** The contact form currently demonstrates input validation and does not send messages directly.
